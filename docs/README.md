# Documentação de privacidade — índice

Este índice reúne os documentos produzidos no Base44 e no ambiente de desenvolvimento. Nenhuma minuta constitui aprovação de prazos, comprovação de exclusão integral ou política vigente por si só.

## Implementação atual

A página `src/pages/Privacidade.jsx` contém os responsáveis e o canal informados pela equipe. A rota `/privacidade` é pública e o cadastro apresenta o link e o aviso de público de 18 anos ou mais. O aviso não verifica idade. A disponibilização no editor por sincronização GitHub não equivale à publicação do app.
